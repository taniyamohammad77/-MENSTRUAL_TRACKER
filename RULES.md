# Development Rules

1. The project is frontend-only.
2. Do not bye
add a backend.
3. Do not add a database.
4. Do not add an API.
5. Do not add unnecessary dependencies.
6. Never assume a cycle length; unknown is valid.
7. Never treat five days as a default period duration.
8. Never treat an unrecorded month as a missed period.
9. Do not make medical diagnoses or medical claims.
10. Do not create fake health data.
11. Do not use external services for personal tracking data.
12. Keep code beginner-friendly.
13. Keep responsibilities separated.
14. Do not change unrelated files.
15. Do not delete existing work without approval.
16. Do not add undocumented features.
17. Every implementation phase requires explicit approval.
18. After every phase, report:
    - Files changed
    - What changed
    - Tests performed
    - Problems found
    - Remaining work
19. Stop after each phase and wait for approval.
20. Never claim a feature works without verifying it.
